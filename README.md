# vehicle-parking-app-v1 <hr> 
#### It is a multi-user app (one requires an administrator and other users) that manages different parking lots, parking spots and parked vehicles. This parking app is for 4-wheeler parking only.

### Frameworks used <hr>
<li>Flask for application back-end
<li>Jinja2 templating, HTML, CSS and Bootstraps for application front-end
<li>SQLalchemy - for database ORM
<li>Flask-SQLalchemy – Flask extension for simplifying SQLalchemy Operations
<li>SQLite for database

### How to run the Project <hr>
<li>Make sure You have Python installed on your Machine.<br><br>
<li>Install all the required Python Modules From the requirement.txt file.<br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;For that oepn the Terminal in root directory of the Project.<br> 
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Then Run the command - <pre>pip install -r requirement.txt</pre><br>
<li>With your Terminal in the root directory.<br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Run - <pre>python app.py</pre><br>
<li>Now Open Your Browser And Go to - <a href="http://127.0.0.1">http://127.0.0.1</a><br><br>
